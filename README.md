# Pokémon Añil PLUS+

Mod co-op para **Pokémon Añil 4.13**: hasta 8 jugadores en la misma sala,
combates en pareja, dúo contra dúo, locke compartido y bastantes cosas más.

Este repositorio solo tiene el mod. El juego no está aquí: necesitas tener
Pokémon Añil 4.13.

## Instalar (Windows)

1. Ve a [Releases](../../releases/latest) y descarga `Launcher_vX.exe`.
2. Ponlo en la carpeta del juego, donde está `Game.exe`, y cámbiale el nombre
   a `Launcher.exe` si quieres.
3. Ábrelo y dale a **Instalar**. A partir de ahí, ábrelo siempre desde el
   launcher: si hay versión nueva te sale y le das a Actualizar.
4. En el desplegable **Versión** puedes elegir otra versión publicada (por
   defecto, la última). Para jugar juntos, todos con la misma.

La primera vez Windows puede avisar con "Windows protegió su PC" porque el
launcher no está firmado: *Más información > Ejecutar de todas formas*.

## Instalar (Linux / Steam Deck)

Descarga `launcher.sh` de Releases, ponlo en la carpeta del juego y ábrelo con
`bash launcher.sh`. Hace lo mismo y abre el juego con Wine.

## Qué hace el launcher

- Lee la lista de versiones de este repositorio (solo lectura, sin cuenta ni
  claves) y te enseña las novedades.
- Descarga el zip del mod, comprueba que ha llegado bien y lo copia en la
  carpeta del juego. Solo toca `CoopAnil/`, `Graphics/`, el plugin del co-op y
  `Data/PluginScripts.rxdata` (del que guarda copia la primera vez).
- No manda nada tuyo a ningún sitio y no toca tus partidas.
